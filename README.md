## 🧠 O Desafio

O **InspirePixel** é uma plataforma desenvolvida para oferecer inspiração visual de forma rápida, organizada e moderna.

A missão proposta pelo **Vai na Web** foi desenvolver uma página web funcional que consumisse uma API externa de imagens, garantindo responsividade e código limpo, solucionando a dificuldade de encontrar referências visuais de qualidade em um só lugar.

### 🧰 Requisitos Técnicos Cumpridos:
* [x] Desenvolvimento com **Vue.js**.
* [x] Estilização avançada com **SASS (SCSS)**.
* [x] Consumo de API de imagens (**Lorem Picsum**) utilizando **Axios**.
* [x] Layout totalmente **responsivo** (Mobile & Desktop).
* [x] Hospedagem online (Deploy).

## 🚀 Diferenciais Implementados (UI/UX)

Além dos requisitos básicos, o projeto conta com um toque extra de design:

* **Ícones Animados:** Utilização da biblioteca `line-md` (via Iconify) para criar feedbacks visuais interativos nos ícones de busca e conta.
* **Minimalismo Refinado:** Ajuste de espessura de traço (`stroke-width`) via CSS para garantir elegância visual.
* **Menu Mobile Fluido:** Navegação otimizada para dispositivos móveis com animações suaves.
* **Identidade Visual:** Logo e Favicon personalizados para o projeto.

## 🛠️ Tecnologias Utilizadas

* **Vue.js 3** (Composition API)
* **Vite** (Build Tool)
* **SASS / SCSS** (Pré-processador CSS)
* **Axios** (Requisições HTTP)
* **Iconify** (Ícones vetoriais)
* **Lorem Picsum API** (Banco de imagens)
